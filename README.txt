DSC401-6 Interactive AI Quiz Game

Files:
- app.py: Streamlit app with 50 questions and answer feedback.
- requirements.txt: dependency list.
- question_bank.json: separate question bank and answer key.
- README.txt: these instructions.

Run on Mac:
1. Open Terminal.
2. Go to the folder where these files are saved. Example: cd ~/Desktop/ai_quiz_game
3. Install Streamlit: python3 -m pip install -r requirements.txt
4. Run: python3 -m streamlit run app.py
5. Open http://localhost:8501 if the browser does not open automatically.

Publish online:
1. Create a GitHub repository called ai-quiz-game.
2. Upload app.py and requirements.txt. You can also upload question_bank.json as the separate answer bank.
3. Go to https://share.streamlit.io/ and connect GitHub.
4. Create an app, select the repository/branch, choose app.py, and deploy.
5. Test the public link and check all quiz features.

The quiz includes MCQs, True/False, Assertion–Reason, Fill in the Blanks, Match the Following, scenarios and search/state-space problems. Review all answers against your class notes before submission.
